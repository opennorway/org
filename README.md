# Open Norway

This repository will serve as the primary source for documents and governance descriptions. The scope of this repository is subject for change.  

## Mission statement 

### English

The organization Open Norway aims to act as a catalyst for open source and standards in Norway by spreading awareness, work towards legislators and politicians, and support initiatives towards both public and private sector to ensure the country is digitally sovereign and participates in further development and innovation.

### Norsk

Foreningen Open Norway ønsker å være en katalysator for åpen kildekode og standarder i Norge. Dette skal vi oppnå med å spre kunnskap, jobbe mot lovgivere og politikere, samt støtte initiativer både i mot offentlig og privat sektor for å forsikre at landet er digitalt suverent og delaktig i videre utvikling og innovasjon.
